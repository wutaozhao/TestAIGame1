# 03 胜负与重开

Status: ready-for-agent
Blocked by: 02 出拳与扣血

## 目标

两名玩家能打完一局、看到结果，并按 `R` 开始下一局。见[第一版玩法总单](../spec.md)。

## 验收条件

- [ ] 单方血量归零时，显示另一方获胜。双方各剩 10 血并在同一次判定中互相命中时，显示平局。
- [ ] 结算后双方停止移动、跳跃和出拳，画面提示按 `R` 重开。
- [ ] 对局中和结算后都能按 `R` 重开。双方回到开局位置和朝向，各恢复 100 血，并清除上一局的出拳、跳跃和结算状态。

## 交付与试玩

交付时注明要打开的场景，以及是否需要在 Cocos Creator 编辑器中手动绑定组件。用户试玩确认后，再把结果写入本工单。
