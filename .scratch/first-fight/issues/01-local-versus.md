# 01 双人上擂台

Status: ready-for-agent
Blocked by: 无

## 目标

打开场景后，两名玩家能用同一把键盘控制红蓝方块，在固定擂台上移动和跳跃。见[第一版玩法总单](../spec.md)。

## 验收条件

- [x] 开局红左蓝右，双方相向。红方用 `A` / `D` 移动、`W` 跳跃，蓝方用 `←` / `→` 移动、`↑` 跳跃。
- [x] 双方可以同时操作。同一方同时按住左右键时停止水平移动，保留最近一次有效的朝向。
- [x] 方块到达擂台两侧时停住，落地后站稳，双方可以穿过彼此换边。
- [x] 角色从地面起跳，空中可以左右移动。按住跳跃键只跳一次，落地后再次按下才能再跳。

## 交付与试玩

交付时注明要打开的场景，以及是否需要在 Cocos Creator 编辑器中手动绑定组件。用户试玩确认后，再把结果写入本工单。
